# Unicode Character Analyzer

A single-page web application that helps you detect, replace, and clean invisible or unusual Unicode characters from text. This tool is particularly useful for removing watermarks or steganographic markers that might be embedded in text generated by AI language models.

## Features

- **Detect Invisible Characters**: Identifies non-breaking spaces, zero-width characters, byte order marks, and other invisible Unicode characters.
- **Visual Highlighting**: Shows all detected characters with their Unicode codes and highlights them for easy identification.
- **Intelligent Character Replacement**: Provides smart substitution of special characters with their visible equivalents (e.g., replacing non-breaking spaces with regular spaces).
- **Clean LLM Watermarks**: Helps remove potential watermarks or tracking mechanisms embedded in AI-generated text.
- **Character Statistics**: Displays detailed counts of invisible characters detected, replaced, and removed.
- **Client-Side Operation**: No server requests - everything runs in your browser for complete privacy.

## Why This Tool Matters

Invisible Unicode characters are increasingly used as **watermarks** or **steganographic markers** in digital text:

- Recent findings suggest that AI systems like ChatGPT may embed invisible markers in generated text
- These markers can potentially be used to track the origins of text or identify AI-generated content
- Zero-width characters and other non-printing Unicode can serve as covert identifiers
- This tool helps you detect and remove such potential tracking mechanisms

## How to Use

1. Open `index.html` in any modern web browser.
2. Paste or type your text in the "Input Text" area.
3. Click the "Analyze Text" button (or wait for automatic analysis).
4. View the highlighted characters in the "Character Analysis" section.
5. See the processed text with appropriate replacements in the "Processed Text" section.
6. Use the "Copy to Clipboard" button to copy the clean text.
7. Click "Clear All" to reset all fields.
8. Try the "Load Sample Text" button to see examples of invisible characters.

## Characters Detected

The application detects the following types of invisible or special Unicode characters:

- Non-breaking spaces (U+00A0)
- Zero-width characters (U+200B, U+200C, U+200D, U+2060)
- Byte Order Mark (U+FEFF)
- Various space characters (En, Em, Hair, etc.)
- Directional formatting characters
- And many more (see full list in the code)

## Technical Implementation

This application is built with pure HTML, CSS, and JavaScript without any external libraries. It works by:

1. Parsing the input text character by character
2. Checking each character against a predefined list of special Unicode characters
3. Highlighting detected characters while building a clean version of the text
4. Updating the UI with the results

## Browser Compatibility

Works in all modern browsers that support ES6 JavaScript.
